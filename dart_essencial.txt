Exercício 1.2

- Crie uma variável 'final' com o nome do seu app (ex.: "Meu App").

final String MeuApp;

- Crie uma constante 'const' com o valor 100 (limite máximo de algo).

const int max = 100.

- Justifique mentalmente: por que "final now = DateTime.now();" é válido e 

  "const now = DateTime.now();" não é?

final (Tempo de Execução / Runtime): O valor é atribuído quando o programa já está a rodar. Como DateTime.now() 
precisa de consultar o relógio do sistema no exato momento em que a linha é executada, ele só pode ser conhecido em tempo de execução. 
Por isso, final funciona.

const (Tempo de Compilação / Compile-time): O valor precisa de ser conhecido antes de o programa rodar 
(quando o código está a ser compilado/construído). Como o computador não tem como saber o horário exato
em que o utilizador vai abrir a aplicação no futuro, DateTime.now() falha com const.
